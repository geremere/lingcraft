# FORM/USE: 'NOT ONLY ? (BUT) ALSO' WITH INVERSION

**EGP #1198** · **C1** · `egp-1198`

## Can-do

Can use auxiliary 'do' + inverted subject after 'not only', to give focus.

## Example

Not only was it in a wonderful location, with extraordinary views, but it was also very accessible and the shops were really near. (Greece; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 2009; Greek; Pass)
