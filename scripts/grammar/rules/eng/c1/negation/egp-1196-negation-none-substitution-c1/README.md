# FORM: 'NONE', SUBSTITUTION

**EGP #1196** · **C1** · `egp-1196`

## Can-do

Can use negative pronoun 'none' to substitute for subject and object pronouns or noun phrases. ► pronouns: substitution

## Example

In fact, there are none, but the hills that do exist can be dubbed mountains - just because there are none... (Russia; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 2005; Russian; Pass)
