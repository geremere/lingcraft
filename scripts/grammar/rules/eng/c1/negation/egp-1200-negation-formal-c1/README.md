# USE: FORMAL

**EGP #1200** · **C1** · `egp-1200`

## Can-do

Can use '(very) few' meaning 'not many' to refer to people in formal written contexts, often reports or surveys.

## Example

They were sent to Britain to improve their English but few had any real contact with the language. (Sweden; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 2000; Swedish; Pass)
