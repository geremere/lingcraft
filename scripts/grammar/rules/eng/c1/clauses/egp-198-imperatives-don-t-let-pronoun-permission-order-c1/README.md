# FORM/USE: DON'T 'LET' + PRONOUN, PERMISSION, ORDER

**EGP #198** · **C1** · `egp-198`

## Can-do

Can use an imperative clause with  'let' + 'him/her/them' + base form of a main verb, to disallow something or instruct someone to disallow something.

## Example

Don't let them spend all their free time in front of the TV. (Sweden; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 1999; Swedish; Pass)
