# FORM/USE: 'LET' + THIRD PERSON PRONOUN, PERMISSION, ORDER

**EGP #197** · **C1** · `egp-197`

## Can-do

Can use an imperative clause with  'let' + 'him/her/them' + base form of a main verb, to  give permission or allow something or instruct someone to allow something.

## Example

Try to play chess with him whenever you can and remember: Let him win! (Greece; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 1993; Greek; Pass)
