# FORM/USE: 'IF' + PAST PERFECT + MODAL VERBS IMAGINED SITUATION, REGRET

**EGP #1120** · **C1** · `egp-1120`

## Can-do

Can form conditional subordinate clauses with if + the past perfect simple and modal verb + 'have' + '-ed' in the main clause, to talk about imagined situations in the past, often with regret.

## Example

All this could have been avoided, if the plan had been more flexible. (Poland; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 1993; Polish; Pass)
