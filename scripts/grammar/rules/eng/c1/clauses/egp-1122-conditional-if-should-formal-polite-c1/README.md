# FORM/USE: 'IF' + 'SHOULD', FORMAL, POLITE

**EGP #1122** · **C1** · `egp-1122`

## Can-do

Can form subordinate conditional clauses with 'if you should', in polite, formal contexts.

## Example

If you should have any concerns about my choice, please tell me. (Germany; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 2008; German; Pass)
