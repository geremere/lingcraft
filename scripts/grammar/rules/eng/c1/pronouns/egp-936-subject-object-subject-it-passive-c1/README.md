# FORM/USE: (SUBJECT) 'IT' + PASSIVE

**EGP #936** · **C1** · `egp-936`

## Can-do

Can use 'it' with the passive voice where the subject is unknown or unimportant, often in formal contexts. ► passives

## Example

It was considered to be the most important thing to supply every computer with Internet and E-mail access (Certificate in Advanced English; C1; German)
