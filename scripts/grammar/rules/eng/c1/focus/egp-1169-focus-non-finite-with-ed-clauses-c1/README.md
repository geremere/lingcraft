# FORM/USE: NON-FINITE WITH '-ED' CLAUSES

**EGP #1169** · **C1** · `egp-1169`

## Can-do

Can use a non-finite subordinate clause with an '-ed' form, before a main clause, for focus, often in formal, academic or business contexts.

## Example

Compared to other European capitals, there has been a lot done to make riding a bike less dangerous and more comfortable in Berlin. (Germany; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 1998; German; Pass)
