# USE: 'BE SET TO', ASSERTION

**EGP #483** · **C1** · `egp-483`

## Can-do

Can use 'be set to' to talk about strong assertion about the future, especially in institutional contexts.

## Example

The turnover of our company is set to increase dramatically after the establishment of the e-shop, which itself requires little investment. (China; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 2002; Chinese; Pass)
