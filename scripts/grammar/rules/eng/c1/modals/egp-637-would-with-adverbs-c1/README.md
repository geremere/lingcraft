# FORM: WITH ADVERBS

**EGP #637** · **C1** · `egp-637`

## Can-do

Can use an increasing range of adverbs with 'would', including 'strongly', 'easily', 'especially', 'actually', 'absolutely', 'gladly'  ► adverbs
