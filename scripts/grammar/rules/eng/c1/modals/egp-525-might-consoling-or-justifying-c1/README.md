# USE: CONSOLING OR JUSTIFYING

**EGP #525** · **C1** · `egp-525`

## Can-do

Can use 'might' followed by 'but' to console or justify.

## Example

The argument that fashion reflects people's attitudes and behaviour might sound superficial, but on closer examination it turns out to be true. (Swiss German, C1 EFFECTIVE OPERATIONAL PROFICIENCY, Pass, 2004)
