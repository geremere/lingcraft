# USE: HABITUAL AND TYPICAL

**EGP #614** · **C1** · `egp-614`

## Can-do

Can use 'will' to talk about something which is typical or habitual.

## Example

The abundance of ingredients required in any recipe will result normally in a spicy but nutritious dish, a dish that will usually contain some kind of sauce made of hot pepper, tomatoes, garlic and onion, some kind of meat and also some vegetables.
