# FORM/USE: MODIFYING ADJECTIVES, HEDGING

**EGP #434** · **C1** · `egp-434`

## Can-do

Can modify adjectives with degree adverbs, often to make an assertion less direct.

## Example

If you want to come earlier or if there's a public transport strike (which is quite probable), you will have to take a taxi. (Poland; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 1993; Polish; Pass)
