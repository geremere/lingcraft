# FORM/USE: 'NOT ONLY … BUT ALSO'

**EGP #272** · **C1** · `egp-272`

## Can-do

Can use 'not only … but also' to combine phrases and clauses, often for focus or emphasis.

## Example

This book is not only a guide to the history of music but also a compendium of theory. (Spain; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 1999; Catalan; Pass)
