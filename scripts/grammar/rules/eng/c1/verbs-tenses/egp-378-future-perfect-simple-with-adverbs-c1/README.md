# FORM: WITH ADVERBS

**EGP #378** · **C1** · `egp-378`

## Can-do

Can use the future perfect with adverbs (in the normal mid-position).

## Example

If you have ever read a fairytale by Hans Christian Andersen you will surely have discovered why this man is so famous worldwide. (Denmark; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 2001; Danish; Pass)
However, sales will possibly have fallen to 5000 units again by the end of the year. (Switzerland; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 2006; German; Pass)
