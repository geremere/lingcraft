# FORM: INVERSION WITH 'NOT ONLY ? BUT ALSO'

**EGP #803** · **C1** · `egp-803`

## Can-do

Can use the inverted form of the past simple with auxiliary 'do', in the phrase 'not only ? but also'.

## Example

The companies I found at the trade fair were very varied. Not only did I find high-technology companies, but also shoemakers, advertisement companies and plane manufacturers to name but a few. (United Kingdom; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 2003; Dutch; Pass)
