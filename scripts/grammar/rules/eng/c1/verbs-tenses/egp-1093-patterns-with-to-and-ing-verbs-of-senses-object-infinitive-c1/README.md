# FORM/USE: VERBS OF SENSES + OBJECT + INFINITIVE

**EGP #1093** · **C1** · `egp-1093`

## Can-do

Can use some verbs connected with the senses + direct object + infinitive without 'to' emphasising a complete action.

## Example

I would like to see it develop without any pollution and without destroying the environment. (Greece; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 2003; Greek; Fail)
