# FORM: DETERMINERS 'NO'

**EGP #1183** · **A2** · `egp-1183`

## Can-do

Can use determiner 'no' with nouns.  ► Determiners: quantity

## Example

I bought these clothes because I need them for my new job, but now I have no money because they cost £250. (Spain; A2 WAYSTAGE; 2008; Spanish - European; Pass)
