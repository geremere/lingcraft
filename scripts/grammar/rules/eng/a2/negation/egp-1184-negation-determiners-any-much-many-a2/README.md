# FORM: DETERMINERS 'ANY', 'MUCH', 'MANY'

**EGP #1184** · **A2** · `egp-1184`

## Can-do

Can use determiners 'any', 'much' and 'many' with nouns in negative contexts. ► Determiners: quantity

## Example

I bought them because I didn't have any shirts or hats. (Portugal; A2 WAYSTAGE; 2008; Portuguese; Pass)
