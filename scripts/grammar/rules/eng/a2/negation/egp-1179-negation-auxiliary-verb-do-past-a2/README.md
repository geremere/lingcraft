# FORM: AUXILIARY VERB 'DO', PAST

**EGP #1179** · **A2** · `egp-1179`

## Can-do

Can form negative statements of main verbs in the past simple with 'didn?t' + main verb. ► past simple

## Example

It was very sad that you didn't come to my birthday party but it's ok. (India; A2 WAYSTAGE; 2004; Hindi; Pass)
