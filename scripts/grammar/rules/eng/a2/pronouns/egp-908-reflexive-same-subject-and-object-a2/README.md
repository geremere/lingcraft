# FORM: SAME SUBJECT AND OBJECT.

**EGP #908** · **A2** · `egp-908`

## Can-do

Can use a limited range of singular reflexive pronouns ('myself', 'yourself') with a limited range of verbs ('enjoy', 'buy') to refer to actions where the subject and object of the verb are the same.

## Example

I enjoyed myself so much. (Vietnam; A2 WAYSTAGE; 2009; Vietnamese; Pass)
