# FORM/USE: WITH ADJECTIVE, SPECIFYING

**EGP #987** · **A2** · `egp-987`

## Can-do

Can modify 'something' or 'anything' with an adjective, to make it more specific.

## Example

Next weekend it's my mum's birthday party, so I needed something new to wear. (Cyprus; A2 WAYSTAGE; 2008; Greek; Pass)
