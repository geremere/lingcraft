# FORM: 'SOME' AS SUBJECT AND OBJECT

**EGP #957** · **A2** · `egp-957`

## Can-do

Can use 'some' as a subject and object to refer back to a plural or uncountable noun.

## Example

I saw a lot of people on the beach, some were playing football and some were sunbathing. (A2 WAYSTAGE; 2011; Somali; Pass
