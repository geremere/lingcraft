# FORM: 'ONE'

**EGP #970** · **A2** · `egp-970`

## Can-do

Can use 'one' as a pronoun to substitute for singular countable nouns which have already been mentioned or are obvious from the context.

## Example

[talking about a phone] I chose the black one with the numbers in orange. (Spain; A2 WAYSTAGE; 2007; Spanish - European; Pass)
