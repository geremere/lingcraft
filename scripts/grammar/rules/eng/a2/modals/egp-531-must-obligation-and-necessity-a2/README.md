# USE: OBLIGATION AND NECESSITY

**EGP #531** · **A2** · `egp-531`

## Can-do

Can use 'must' with a limited range of pronouns ('I' and 'you') to talk about obligation and necessity.

## Example

[talking about a mobile phone] It is very important to me because I must call my parents. (Spanish - Latin American, A2 WAYSTAGE)
