# FORM/USE: AFTER 'IF', FUTURE SITUATIONS

**EGP #605** · **A2** · `egp-605`

## Can-do

Can use 'will' in the main clause after an 'if-' clause to talk about possible future situations. ► conditionals

## Example

If I need a camera, I will use my mobile phone. (Turkey; A2 WAYSTAGE; 2007; Turkish; Pass)
