# FORM/USE: NEGATIVE

**EGP #189** · **A2** · `egp-189`

## Can-do

Can form a negative imperative with the auxiliary verb 'do' + 'n't' + base form of a main verb, to give advice, instructions or orders.

## Example

Don't tell Lucy, please. (Mexico; A2 WAYSTAGE; 2007; Spanish - Latin American; Pass)
