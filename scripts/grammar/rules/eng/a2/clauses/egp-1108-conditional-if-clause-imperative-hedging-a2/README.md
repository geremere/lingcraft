# USE: 'IF' CLAUSE + IMPERATIVE, HEDGING

**EGP #1108** · **A2** · `egp-1108`

## Can-do

Can use an 'if-' clause ('if you want', 'like', 'prefer') to soften the directness of imperatives, offers or suggestions.

## Example

Bring some films if you want. (Spain; A2 WAYSTAGE; 2009; Spanish - European; Pass)
