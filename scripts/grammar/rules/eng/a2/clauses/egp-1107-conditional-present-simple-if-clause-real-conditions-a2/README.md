# FORM/USE: PRESENT SIMPLE 'IF' CLAUSE, REAL CONDITIONS

**EGP #1107** · **A2** · `egp-1107`

## Can-do

Can use 'if' + present simple with present simple, 'can' or imperative in the main clause to refer to things that are true now or very likely to happen.

## Example

If I have spare time I always read a book. (Turkey; A2 WAYSTAGE; 2004; Turkish; Pass)
