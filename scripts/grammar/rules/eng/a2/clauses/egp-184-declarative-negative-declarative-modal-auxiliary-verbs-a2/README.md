# FORM: NEGATIVE DECLARATIVE, MODAL AUXILIARY VERBS

**EGP #184** · **A2** · `egp-184`

## Can-do

Can form a simple negative declarative clause with modal verb + 'not' or 'n't'.

## Example

I know you couldn't come to my party so I want to tell you about my presents and party. (Turkey; A2 WAYSTAGE; 2004; Turkish; Pass)
