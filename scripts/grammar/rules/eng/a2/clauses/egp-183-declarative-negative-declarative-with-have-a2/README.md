# FORM: NEGATIVE DECLARATIVE WITH 'HAVE'

**EGP #183** · **A2** · `egp-183`

## Can-do

Can form a simple negative declarative clause with auxiliary 'have' + 'not' or 'n't' and 'have' + 'not' or 'n't (got)'

## Example

I haven't eaten Italian food for a long time. (Ecuador; A2 WAYSTAGE; 2003; Spanish - Latin American; Pass)
