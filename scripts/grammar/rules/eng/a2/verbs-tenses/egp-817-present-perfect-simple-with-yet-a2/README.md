# FORM/USE: WITH 'YET'

**EGP #817** · **A2** · `egp-817`

## Can-do

Can use the negative form with 'yet' to talk about events which are expected to be completed at some point in the future.

## Example

[talking about a new mobile phone] I haven't seen it yet . (Cyprus; A2 WAYSTAGE; 2009; Greek; Pass)
