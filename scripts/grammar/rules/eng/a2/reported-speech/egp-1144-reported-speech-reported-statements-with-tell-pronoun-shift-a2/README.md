# FORM: REPORTED STATEMENTS WITH 'TELL', PRONOUN SHIFT

**EGP #1144** · **A2** · `egp-1144`

## Can-do

Can report statements using a reporting clause with 'tell' + direct object + 'that-'clause, with a pronoun shift where relevant.

## Example

[about a mobile phone] It's very important to me to have it with me because my brother is in the hospital and my father told me that he will call. (Argentina; A2 WAYSTAGE; 2005; Spanish - Latin American; Pass)
