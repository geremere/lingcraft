# FORM: REPORTED STATEMENTS WITH 'SAY', PRONOUN SHIFT

**EGP #1143** · **A2** · `egp-1143`

## Can-do

Can report statements using a reporting clause with 'say' + 'that-'clause, with a pronoun shift where relevant.

## Example

My mother said that she can take us there. (Brazil; A2 WAYSTAGE; 2008; Portuguese; Pass)
