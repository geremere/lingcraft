# FORM: WITH RELATIVE CLAUSE AS POSTMODIFIER

**EGP #654** · **A2** · `egp-654`

## Can-do

Can post-modify noun phrases by using a non-defining relative clause. ► Clauses: relative

## Example

She's in a volleyball team like me, but we're not in the same one. She was for the other team, which lost. (Switzerland; A2 WAYSTAGE; 2007; Swiss German; Pass)
