# USE: 'THIS', ALREADY MENTIONED

**EGP #304** · **A2** · `egp-304`

## Can-do

Can use 'this' to refer to something with immediate relevance which has already been mentioned. ► noun phrases ►  pronouns: demonstrative

## Example

Could you send someone who can check where the problem is and try to do something about this problem. (A2 WAYSTAGE; 2009; Polish; Pass)
