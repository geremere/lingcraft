# USE: 'THAT', ALREADY MENTIONED

**EGP #307** · **A2** · `egp-307`

## Can-do

Can use 'that' to refer to something which has already been mentioned. ► noun phrases ►  pronouns: demonstrative

## Example

Yesterday, I went shopping to Collesione for clothes. I bought a skirt and a T-shirt, because we have a party this week. They were very cheap. They cost £10. You should go that shop. (Turkey; A2 WAYSTAGE; 2008; Turkish; Pass)
