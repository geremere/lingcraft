# USE: 'THOSE', ALREADY MENTIONED

**EGP #312** · **A2** · `egp-312`

## Can-do

Can use 'those' to refer to things which have already been mentioned. ► noun phrases ►  pronouns: demonstrative

## Example

I went shopping for clothes yesterday. I bought some jumpers and trousers. I bought those clothes because I'm going to Japan next Friday and there the weather is cold. (Malaysia; A2 WAYSTAGE; 2008; Chinese; Pass)
