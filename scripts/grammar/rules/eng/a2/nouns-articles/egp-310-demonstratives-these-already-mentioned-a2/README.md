# USE: 'THESE', ALREADY MENTIONED

**EGP #310** · **A2** · `egp-310`

## Can-do

Can use 'these' to refer to things with immediate relevance or which have already been mentioned. ► noun phrases ►  pronouns: demonstrative

## Example

… you can visit the Old Museum, the Green Park, the old bridge and old church. These places are very old. (Libya; A2 WAYSTAGE; 2001; Arabic - Meghreb; Pass)
