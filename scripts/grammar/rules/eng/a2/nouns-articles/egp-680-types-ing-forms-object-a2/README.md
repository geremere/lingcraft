# FORM: '-ING' FORMS, OBJECT

**EGP #680** · **A2** · `egp-680`

## Can-do

Can use the '-ing' forms of verbs as nouns, in object position, to refer to activities.

## Example

There we did a lot of things like swimming from the beach and going shopping. (Uruguay; A2 WAYSTAGE; 2009; Spanish - Latin American; Pass)
