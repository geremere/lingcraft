# FORM/USE: 'NOT A' + NOUN, EMPHASIS

**EGP #1202** · **C2** · `egp-1202`

## Can-do

Can use 'not a' + noun, often with a following  passive structure, for emphasis.

## Example

Not a single noise could be heard from inside of any of the rooms. (Argentina; C2 MASTERY; 2000; Spanish - Latin American; Pass)
