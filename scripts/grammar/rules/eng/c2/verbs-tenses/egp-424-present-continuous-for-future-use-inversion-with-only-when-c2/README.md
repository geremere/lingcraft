# FORM: INVERSION WITH 'ONLY WHEN'

**EGP #424** · **C2** · `egp-424`

## Can-do

Can use the present simple with 'only when' (followed by 'will' and inverted subject) to refer to the future.

## Example

Only when we understand that, will we be able to live in better societies. (C2 Spanish - Latin American)
