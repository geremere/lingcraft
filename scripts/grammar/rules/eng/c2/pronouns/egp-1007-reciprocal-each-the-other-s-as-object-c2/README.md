# FORM: 'EACH ... THE OTHER(S)', AS OBJECT

**EGP #1007** · **C2** · `egp-1007`

## Can-do

Can use 'each' (+ noun or pronoun) as subject followed by 'the other(s)' as object , to refer to two related things. ► pronouns: quantity

## Example

Each of them admires the other's intelligence. (Italy; C2 MASTERY; 1993; Italian; Pass)
