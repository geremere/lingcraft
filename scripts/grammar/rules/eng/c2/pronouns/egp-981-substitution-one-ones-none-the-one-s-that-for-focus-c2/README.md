# FORM/USE: 'THE ONE(S) THAT', FOR FOCUS

**EGP #981** · **C2** · `egp-981`

## Can-do

Can use 'The one(s) that' + clause in subject position, for focus. ► focus

## Example

The one that impressed me a lot is the Chinese Lunar New Year Carnival which was held in Hong Kong in January this year. (Hong Kong; C2 MASTERY; 1998; Chinese; Pass)
