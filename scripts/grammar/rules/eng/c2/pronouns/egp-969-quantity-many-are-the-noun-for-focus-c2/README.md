# FORM/USE: 'MANY ARE THE' + NOUN, FOR FOCUS

**EGP #969** · **C2** · `egp-969`

## Can-do

Can form complex noun phrases using an inverted form 'Many' + 'are' + noun phrase, followed by a relative clause, as a focusing device.  ► focus

## Example

Many are the causes which have led us to a better and longer life. (Spain; C2 MASTERY; 1993; Catalan; Pass)
