# FORM/USE: 'IF IT WERE' + 'TO'-INFINITIVE FORM, FORMAL

**EGP #1130** · **C2** · `egp-1130`

## Can-do

Can use 'If it were' + 'to-' infinitive to introduce conditions in formal contexts.

## Example

If it were to be published, the first issue would probably include a small introduction about the people who helped in the creation of the magazine. (Greece; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 2001; Greek; Pass)
