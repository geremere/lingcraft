# USE: INVERTED 'SHOULD', FUTURE, POSSIBLE OUTCOME, FORMAL, POLITE

**EGP #1124** · **C2** · `egp-1124`

## Can-do

Can use inverted 'should', + 'would' in the main clause to talk about possible future outcomes, in polite or formal contexts.

## Example

Should we win your prize we would like to build a new school close to our production center, for the children of the area. (Switzerland; C1 EFFECTIVE OPERATIONAL PROFICIENCY; 2004; German; Pass)
