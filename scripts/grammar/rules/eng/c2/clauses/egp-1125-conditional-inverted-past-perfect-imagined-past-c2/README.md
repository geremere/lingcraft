# FORM/USE: INVERTED PAST PERFECT, IMAGINED PAST

**EGP #1125** · **C2** · `egp-1125`

## Can-do

Can use past perfect +  inverted subject, and a modal verb + 'have' + '-ed' in the main clause  to talk about imagined situations in the past.

## Example

Had he been more experienced he would have known that these things always happen in this part of the world. (Sweden; C2 MASTERY; 2001; Swedish; Pass)
