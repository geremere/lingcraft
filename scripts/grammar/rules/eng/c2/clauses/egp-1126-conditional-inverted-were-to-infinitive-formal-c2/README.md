# FORM/USE: INVERTED 'WERE' + 'TO' INFINITIVE, FORMAL

**EGP #1126** · **C2** · `egp-1126`

## Can-do

Can use 'were' with an inverted subject + 'to' infinitive, to introduce conditions in formal contexts. ► past simple

## Example

Were I to win this travel scholarship, the country of my choice would be Japan. (Switzerland; C2 MASTERY; 2001; German; Pass)
