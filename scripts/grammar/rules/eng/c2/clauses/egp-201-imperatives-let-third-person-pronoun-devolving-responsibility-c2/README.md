# FORM/USE: 'LET' + THIRD PERSON PRONOUN, DEVOLVING RESPONSIBILITY

**EGP #201** · **C2** · `egp-201`

## Can-do

Can use an imperative clause with 'let' + 'him/her/them' + base form of a main verb, to devolve responsibility.

## Example

Let them find their own food. (Portugal; C2 MASTERY; 1993; Portuguese; Pass)
