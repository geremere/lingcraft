# FORM/USE: 'IF IT WERE NOT FOR', FORMAL

**EGP #1129** · **C2** · `egp-1129`

## Can-do

Can use 'If it weren?t / were not for' + noun phrase to introduce conditions in formal contexts. ► past simple

## Example

If it weren't for that boy, I am definitely certain that I would have failed the examinations and I would have ended up taking the class again the following year. (Greece; C2 MASTERY; 2009; Greek; Pass)
