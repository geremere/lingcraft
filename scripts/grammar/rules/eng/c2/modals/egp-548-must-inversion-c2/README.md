# FORM: INVERSION

**EGP #548** · **C2** · `egp-548`

## Can-do

Can invert 'must' and the subject after negative phrases, e.g. 'not only', 'never', 'nor', to change the focus and give prominence/emphasis.

## Example

Not only must you study really hard during university, but also keep studying afterwards. (Portuguese, C2 MASTERY)
