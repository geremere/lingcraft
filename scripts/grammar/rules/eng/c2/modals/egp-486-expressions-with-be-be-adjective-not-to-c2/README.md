# FORM/USE: 'BE' + ADJECTIVE + 'NOT' + 'TO'

**EGP #486** · **C2** · `egp-486`

## Can-do

Can use 'be' + adjective + 'not' + 'to' + infinitive for emphasis.

## Example

People should be obliged not to have more than a very small number of children otherwise they will be punished. (Greece; C2 MASTERY; 1993; Greek; Pass)
