# FORM: WITH ADVERBS

**EGP #550** · **C2** · `egp-550`

## Can-do

Can use 'must' with a wide range of adverbs in the normal mid position after the modal verb. ► adverbs|

## Example

There must certainly be other solutions to the problem of the need for space for new houses. (Greece; C2 MASTERY; 2008; Greek; Pass)
