# FORM/USE: 'THE' + PREMODIFIER + 'THING, FACT etc.' + 'IS (THAT)'

**EGP #1172** · **C2** · `egp-1172`

## Can-do

Can use 'The' + premodifier + 'thing, fact, point, problem or reason' + 'is (that)' for focus.

## Example

The sad thing about it was that it was actually Richard who said, "Why don't you go on holiday?? (Poland; C2 MASTERY; 1993; Polish; Pass)
