# USE: 'THIS', IN NARRATIVES

**EGP #315** · **C2** · `egp-315`

## Can-do

Can use 'this' with nouns and noun phrases in a narrative to create a sense of immediacy.

## Example

[talking about two characters in a story] There's this flame of passion between them. (France; C2 MASTERY; 1993; French; Pass)
