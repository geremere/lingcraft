# FORM: COMPOUND NOUNS

**EGP #679** · **A1** · `egp-679`

## Can-do

Can use a range of compound nouns, as one-word, two-word and hyphenated compounds, formed from verb + noun, noun + noun and adjective + noun combinations.

## Example

She likes to go to the swimming pool and to the gym. (A1 BREAKTHROUGH; 2006; Ukrainian; Pass)
