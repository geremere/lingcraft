# USE: 'THIS', POINTING

**EGP #299** · **A1** · `egp-299`

## Can-do

Can use 'this' in a limited range of contexts to refer to places from the speaker's or writer's point of view. ► noun phrases ►  pronouns: demonstrative

## Example

I want to let you know about this area and the shops near here. (A1 BREAKTHROUGH; 2008; ; Pass)
