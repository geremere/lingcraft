# FORM: VERB + PREPOSITION + OBJECT

**EGP #1048** · **A1** · `egp-1048`

## Can-do

Can use a limited range of prepositional verbs followed by noun or pronoun objects.

## Example

I listen to music in the living room, and also eat my breakfast, lunch and dinner. (A1 BREAKTHROUGH; 2009; Dari; Pass)
