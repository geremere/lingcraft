# FORM/USE: WITH 'ALREADY'

**EGP #824** · **B1** · `egp-824`

## Can-do

Can use the present perfect simple with 'already' to emphasise that something is done, often before the expected time.  ► adverbs

## Example

I've already planned the party, bought his present, and most important of all, I 've already told everyone. (Mexico; B1 THRESHOLD; 2004; Spanish - Latin American; Pass)
