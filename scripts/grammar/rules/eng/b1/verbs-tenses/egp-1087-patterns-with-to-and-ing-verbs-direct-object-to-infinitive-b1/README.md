# FORM: VERBS + DIRECT OBJECT + 'TO' INFINITIVE

**EGP #1087** · **B1** · `egp-1087`

## Can-do

Can use some verbs of requesting and commanding followed by a direct object and a 'to-'infinitive.

## Example

I would like you to come to a picnic on Saturday. (Argentina; B1 THRESHOLD; 2009; Spanish - Latin American; Pass)
