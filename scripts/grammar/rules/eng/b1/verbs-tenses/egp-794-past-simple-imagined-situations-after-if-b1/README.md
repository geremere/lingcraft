# USE: IMAGINED SITUATIONS AFTER 'IF'

**EGP #794** · **B1** · `egp-794`

## Can-do

Can use the past simple after 'if' to talk about the possible result of an imagined situation in the present or future.

## Example

It would be better if you spent some time in the fresh air with your friends or walking in a park. (B1, Russian)
