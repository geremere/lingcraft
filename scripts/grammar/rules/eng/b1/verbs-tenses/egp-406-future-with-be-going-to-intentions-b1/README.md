# USE: INTENTIONS

**EGP #406** · **B1** · `egp-406`

## Can-do

Can use the negative form of 'be going to' to talk about plans and intentions.

## Example

I 'm not going to be able to meet you next Tuesday, because I have to go to the dentist at 5.30. (Spain; B1 THRESHOLD; 2008; Spanish - European; Pass)
