# FORM: 'THERE' + MODAL VERBS

**EGP #1100** · **B1** · `egp-1100`

## Can-do

Can use 'there' with a range of modal verbs + 'be' + complement.

## Example

[talking about 20 years in the future] There will be flying cars and buses, and big houses. (Uruguay; B1 THRESHOLD; 2007; Spanish - Latin American; Pass)
