# USE: WITH SUPERLATIVE

**EGP #831** · **B1** · `egp-831`

## Can-do

Can use the present perfect simple with a superlative adjective to talk about a unique experience.  ► adjectives: superlatives

## Example

This restaurant has the most delicious shrimps I have ever tasted. (Mexico; B1 THRESHOLD; 2005; Spanish - Latin American; Pass)
