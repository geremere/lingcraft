# USE: MENTAL PROCESS VERBS

**EGP #880** · **B1** · `egp-880`

## Can-do

Can use the present simple with an increasing a range of mental process verbs, including 'remember', 'understand', 'believe'.

## Example

I'm reading an adventure book, I don't remember the title but it's very boring! (Preliminary English Test, B1, Italian)
