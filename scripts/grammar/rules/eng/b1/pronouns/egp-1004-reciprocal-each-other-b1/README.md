# FORM: 'EACH OTHER'

**EGP #1004** · **B1** · `egp-1004`

## Can-do

Can use 'each other' as the object of a verb or complement of a preposition to talk about the mutual behaviour of two or more people.

## Example

We go to the same school so we see each other every day. (Turkey; B1 THRESHOLD; 2009; Turkish; Pass)
