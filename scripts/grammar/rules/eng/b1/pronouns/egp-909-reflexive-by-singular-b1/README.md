# FORM/USE: 'BY' + SINGULAR

**EGP #909** · **B1** · `egp-909`

## Can-do

Can use the singular reflexive pronouns 'myself', 'yourself', 'himself' and 'herself' with 'by' to mean alone, without any help.

## Example

I will ask my friends from the class and I will study by myself. (Preliminary English Test; B1; Czech)
