# FORM: SUBJECT AND OBJECT PRONOUNS, 'BOTH', 'A FEW', 'ANOTHER'

**EGP #960** · **B1** · `egp-960`

## Can-do

Can use 'both', 'a few', 'another' as subject and object pronouns.

## Example

[talking about two types of exercise] Both are going to keep you fit. (Greece; B1 THRESHOLD; 2009; Greek; Pass)
