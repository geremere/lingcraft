# USE: 'THIS', ALREADY MENTIONED

**EGP #946** · **B1** · `egp-946`

## Can-do

Can use 'this' as a pronoun to refer back to whole clauses or sentences, especially to highlight or continue an important topic.

## Example

To stay fit I'm eating lots of fruit and vegetables, but meat and fish, too. I think you should do this, too, if you haven't done it in the past. (Germany; B1 THRESHOLD; 2009; German; Pass)
