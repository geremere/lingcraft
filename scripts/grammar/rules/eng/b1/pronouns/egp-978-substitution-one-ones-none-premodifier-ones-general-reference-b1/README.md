# FORM/USE: PREMODIFIER + 'ONES', GENERAL REFERENCE

**EGP #978** · **B1** · `egp-978`

## Can-do

Can use premodifiers with 'ones', to refer to something in general.

## Example

Our computers are out-dated and slow. I think we should replace them with new ones. (Switzerland; B1 THRESHOLD; 2009; Swiss German; Pass)
