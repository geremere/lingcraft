# USE: 'THESE', ALREADY MENTIONED

**EGP #948** · **B1** · `egp-948`

## Can-do

Can use 'these' as a pronoun to refer to something with immediate relevance which has already been mentioned.  ►  noun phrases  ►  pronouns: demonstrative

## Example

He is very clever and generous, and these are the things that I like most about him. (Brazil; B1 THRESHOLD; 2009; Portuguese; Pass)
