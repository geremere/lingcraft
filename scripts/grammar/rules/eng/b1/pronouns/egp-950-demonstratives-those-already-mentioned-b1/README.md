# USE: 'THOSE', ALREADY MENTIONED

**EGP #950** · **B1** · `egp-950`

## Can-do

Can use 'those' as a pronoun to refer to things which have already been mentioned.  ►  noun phrases

## Example

Those are the things I like the most about her. (Chile; B1 THRESHOLD; 2009; Spanish - Latin American; Pass)
