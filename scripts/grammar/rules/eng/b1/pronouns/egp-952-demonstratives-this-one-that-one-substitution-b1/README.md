# FORM/USE: 'THIS ONE', 'THAT ONE' SUBSTITUTION

**EGP #952** · **B1** · `egp-952`

## Can-do

Can use 'this one', 'that one' as a substitute for countable singular nouns that have previously been mentioned.

## Example

I don't usually wear dresses but I had to buy this one because I am going to be in a singing competition. (Thailand; B1 THRESHOLD; 2006; Thai; Pass)
