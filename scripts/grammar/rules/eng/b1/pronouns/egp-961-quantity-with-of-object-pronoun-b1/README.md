# FORM: WITH 'OF' + OBJECT PRONOUN

**EGP #961** · **B1** · `egp-961`

## Can-do

Can use an increasing range of pronouns ('some', 'a few', 'any', 'each') with 'of' followed by an object pronoun.

## Example

Of course some of them are closer than others but I love them all. (Uruguay; B1 THRESHOLD; 2009; Spanish - Latin American; Pass)
