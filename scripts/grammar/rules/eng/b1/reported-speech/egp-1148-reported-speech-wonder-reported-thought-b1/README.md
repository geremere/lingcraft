# FORM/USE: 'WONDER', REPORTED THOUGHT

**EGP #1148** · **B1** · `egp-1148`

## Can-do

Can report thought using 'wonder' + 'wh-'word + clause, with a tense shift where relevant.

## Example

I always had good times with her and was very impatient to read this letter: I wondered what she had written. (France; B1 THRESHOLD; 2008; French; Pass)
