# FORM: REPORTED REQUESTS AND COMMANDS

**EGP #1151** · **B1** · `egp-1151`

## Can-do

Can report requests and commands with 'ask' or 'tell' + direct object and 'to-'infinitive.

## Example

She asked me to come back as soon as possible because my father is seriously ill. (Malaysia; B1 THRESHOLD; 2005; Malay; Pass)
