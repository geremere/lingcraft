# USE: 'BE ABLE TO', PAST

**EGP #469** · **B1** · `egp-469`

## Can-do

Can use 'was able to', 'were able to' to talk about facts in the past.

## Example

[about a bus journey] She was able to get a good seat and she unexpectedly got to school early. (Philippines; B1 THRESHOLD; 2009; Tagalog; Pass)
