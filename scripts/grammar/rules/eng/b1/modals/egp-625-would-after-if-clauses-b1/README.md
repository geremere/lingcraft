# FORM/USE: AFTER 'IF' CLAUSES

**EGP #625** · **B1** · `egp-625`

## Can-do

Can use 'would' in the main clause of a conditional sentence to talk about an imagined situation, often in the context of advice or opinion-giving.

## Example

It's your decision but if I had the chance, I would go with my friends. (German, B1 THRESHOLD, Pass, 2008)
