# FORM: WITH ADVERBS

**EGP #534** · **B1** · `egp-534`

## Can-do

Can use 'must' with a limited range of adverbs (most commonly 'also') in the normal mid position after the modal verb. ► adverbs

## Example

I must also do the FCE practice test because I will have the FCE test soon. (Chinese, B1 THRESHOLD)
