# USE: FOCUS

**EGP #521** · **B1** · `egp-521`

## Can-do

Can use 'might' in phrases, such as 'as you might know', 'have already heard', to focus the reader on shared knowledge.

## Example

As you might know, nobody came here until Wednesday afternoon. (Spanish - European, B2 VANTAGE, Pass, 2010)
