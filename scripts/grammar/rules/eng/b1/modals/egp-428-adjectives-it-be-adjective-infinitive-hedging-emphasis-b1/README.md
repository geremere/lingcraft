# FORM/USE: 'IT' + 'BE' + ADJECTIVE + INFINITIVE, HEDGING, EMPHASIS

**EGP #428** · **B1** · `egp-428`

## Can-do

Can use 'it' + 'be' + adjective + 'to' + infinitive, to make an assertion more or less direct.

## Example

Our sales department staff are heavily involved in several international projects, so it is necessary to improve their foreign language skills. (Germany; B1 THRESHOLD; 2006; German; Pass)
