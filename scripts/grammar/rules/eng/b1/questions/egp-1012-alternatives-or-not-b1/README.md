# FORM/USE: 'OR NOT'

**EGP #1012** · **B1** · `egp-1012`

## Can-do

Can form alternative questions using 'or not' to substitute for a clause, sometimes to express annoyance or impatience.

## Example

For a few seconds he was quiet. I couldn't wait, I asked nervously about his exam, did he pass or not? (Poland; B1 THRESHOLD; 2005; Polish; Pass)
