# USE: DIFFERENT (WITH 'ANOTHER')

**EGP #295** · **B1** · `egp-295`

## Can-do

Can use 'another' to talk about something different.

## Example

I'm sorry but I won't be able to go to the English class tomorrow because I'll go to Maldonado to see my mother that is ill. But I can go another day to cover the work I've missed. (Uruguay; B1 THRESHOLD; 2006; Spanish - Latin American; Pass)
