# FORM/USE: 'THE THING …'

**EGP #668** · **B1** · `egp-668`

## Can-do

Can use the noun phrase 'The thing' in front position, with a clause complement, to give focus to something.

## Example

The thing I enjoyed most about it was a new computer game. (Georgia (Republic of); B1 THRESHOLD; 2007; Georgian; Pass)
