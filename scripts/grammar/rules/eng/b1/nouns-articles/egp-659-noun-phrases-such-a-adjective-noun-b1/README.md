# FORM/USE: 'SUCH (A)' + ADJECTIVE + NOUN

**EGP #659** · **B1** · `egp-659`

## Can-do

Can form noun phrases with 'such a' + adjective + singular noun and 'such' + adjective + plural noun, to give emphasis.

## Example

It was so terrible because I've never been in such a terrible situation. (Russia; B1 THRESHOLD; 2000; Russian; Pass)
