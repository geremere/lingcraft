# FORM/USE: 'IF' + PAST PERFECT + 'WOULD HAVE' + '-ED', IMAGINED SITUATION, REGRET|(THIRD CONDITIONAL)

**EGP #1116** · **B1** · `egp-1116`

## Can-do

Can form conditional subordinate clauses with 'if' + past perfect simple and 'would have' + '-ed' in the main clause, to talk about imagined situations in the past, often with regret.

## Example

If they had not been there, I would have been very lonely. (Vietnam; B1 THRESHOLD; 2001; Vietnamese; Pass)
