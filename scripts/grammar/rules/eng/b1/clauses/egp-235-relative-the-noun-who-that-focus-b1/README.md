# FORM/USE: 'THE' + NOUN + 'WHO/THAT', FOCUS

**EGP #235** · **B1** · `egp-235`

## Can-do

Can use defining relative clauses, 'the person who/that, the thing that, the (only) one who/that' as a focusing device.

## Example

The thing that was great is that the weather was really warm and it didn't rain. (France; B1 THRESHOLD; 2003; French; Pass)
