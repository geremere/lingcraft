# FORM/USE: PRESENT CONTINUOUS 'IF' CLAUSE , PLANS &amp; ADVICE

**EGP #1111** · **B1** · `egp-1111`

## Can-do

Can use 'if' + present continuous or 'going to' to introduce a possible plan, with modal verbs or imperatives in the main clause to give advice.

## Example

Billy, if you are moving you should think a lot, first you have to go and see the two schools. (Argentina; B1 THRESHOLD; 2008; Spanish - Latin American; Pass)
