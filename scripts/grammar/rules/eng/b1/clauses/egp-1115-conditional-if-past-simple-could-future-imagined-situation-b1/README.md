# FORM/USE: 'IF' + PAST SIMPLE + 'COULD', FUTURE, IMAGINED SITUATION

**EGP #1115** · **B1** · `egp-1115`

## Can-do

Can form conditional subordinate clauses with 'if' + past simple, and 'could' in the main clause to talk about an imagined situation, often in the context of suggesting.

## Example

If you wanted to do some outdoor activities, we could go fishing or even walking through the green fields. (Egypt; B1 THRESHOLD; 2004; Arabic - Egyptian; Pass)
