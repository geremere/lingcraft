# FORM/USE: PRESENT SIMPLE 'IF' CLAUSE + 'WILL', FUTURE, LIKELY OUTCOME (FIRST CONDITIONAL)

**EGP #1109** · **B1** · `egp-1109`

## Can-do

Can use 'if' + present simple to introduce a possible future condition, with 'will' in the main clause to talk about a likely result.

## Example

I talked to my parents and I think if you tell them your reasons, they will accept it. (Germany; B1 THRESHOLD; 2008; German; Pass)
