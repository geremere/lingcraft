# FORM/USE: PRESENT SIMPLE 'IF' CLAUSE + MODAL, FUTURE, POSSIBLE OUTCOME

**EGP #1110** · **B1** · `egp-1110`

## Can-do

Can use 'if' + present simple to introduce a possible future condition, with modal verbs in the main clause, to talk about a possible result. ► modality

## Example

I think that it would be very good if you start going to the gym or you start cycling. (Colombia; B1 THRESHOLD; 2009; Spanish - Latin American; Pass)
