# FORM/USE: ELLIPTED 'IF SO', CONFIRMING

**EGP #1118** · **B1** · `egp-1118`

## Can-do

Can use 'If so' as a conditional clause to refer a previous direct or indirect 'yes-no' question where the answer might be ?yes?. ► Clauses coordinated

## Example

Do you think we could have an extra class? If so, I'd like to do it to cover the work I'll miss. (Brazil; B1 THRESHOLD; 2006; Portuguese; Pass)
