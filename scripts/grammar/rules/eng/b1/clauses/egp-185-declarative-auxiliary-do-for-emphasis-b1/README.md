# FORM/USE: AUXILIARY 'DO', FOR EMPHASIS

**EGP #185** · **B1** · `egp-185`

## Can-do

Can use the auxiliary verb 'do' in an affirmative declarative clause, for emphasis and affirmation.

## Example

Yes, I do have a favorite restaurant. (Mexico; B1 THRESHOLD; 2005; Spanish - Latin American; Pass)
