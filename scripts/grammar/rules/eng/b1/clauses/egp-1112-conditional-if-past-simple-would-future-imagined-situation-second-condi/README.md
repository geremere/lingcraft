# FORM/USE: 'IF' + PAST SIMPLE + 'WOULD', FUTURE, IMAGINED SITUATION|(SECOND CONDITIONAL)

**EGP #1112** · **B1** · `egp-1112`

## Can-do

Can form conditional subordinate clauses with 'if' + past simple, and would in the main clause, to talk about an imagined situation, often in the context of advice or opinion-giving.

## Example

Maybe it would be more fun if you went with your friends. (Portugal; B1 THRESHOLD; 2008; Portuguese; Pass)
