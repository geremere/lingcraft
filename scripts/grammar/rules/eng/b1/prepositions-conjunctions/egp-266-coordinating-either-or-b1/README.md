# FORM: 'EITHER … OR'

**EGP #266** · **B1** · `egp-266`

## Can-do

Can use 'either … or' to connect two words, phrases or clauses.

## Example

The men wear suits, either white or black, and the bride and women wear special long dresses, usually the same colour. (Yugoslavia; B1 THRESHOLD; 2006; Serbian; Pass)
