# FORM/USE: 'BOTH … AND' WITH NOUNS

**EGP #267** · **B1** · `egp-267`

## Can-do

Can use 'both … and' to combine noun phrases, to give emphasis.

## Example

I felt sorry for you because both friends and family are very important and having to pick one is very hard. (Turkey; B1 THRESHOLD; 2008; Turkish; Pass)
