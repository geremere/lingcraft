# FORM: (SUBJECT) EMPTY 'IT'

**EGP #934** · **B2** · `egp-934`

## Can-do

Can use dummy 'it' with 'appears', 'feels', 'looks' and 'seems'.

## Example

When you watch a film, it seems to be that you are inside it, and you are a character in it. (First Certificate in English; B2; Spanish - Latin American)
