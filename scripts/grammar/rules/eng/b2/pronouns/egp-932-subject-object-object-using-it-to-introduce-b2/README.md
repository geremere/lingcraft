# FORM: (OBJECT) USING 'IT' TO INTRODUCE

**EGP #932** · **B2** · `egp-932`

## Can-do

Can use 'it' as an object with 'make' to introduce something the speaker or writer is going to refer to.

## Example

This shyness makes it hard for me to speak in public, or even to go out with my friends as often as I should. (First Certificate in English; B2; Spanish ? European)
