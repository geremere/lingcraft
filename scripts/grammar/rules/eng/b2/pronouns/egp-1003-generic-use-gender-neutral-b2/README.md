# FORM/USE: GENDER NEUTRAL

**EGP #1003** · **B2** · `egp-1003`

## Can-do

Can use 'he/she', 'he' or 'she' or 'they' to refer back to gender neutral singular nouns or indefinite pronouns when we are not sure of the gender.

## Example

If a child had free time, he/she would play on his/her own and not with other children. (Greece; B2 VANTAGE; 2006; Greek; Pass)
