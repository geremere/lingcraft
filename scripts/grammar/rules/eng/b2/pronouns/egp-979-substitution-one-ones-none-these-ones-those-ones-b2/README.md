# FORM: 'THESE ONES', 'THOSE ONES'

**EGP #979** · **B2** · `egp-979`

## Can-do

Can use 'these ones', 'those ones' as a substitute for plural countable nouns which have already been mentioned or are obvious from the context.

## Example

This is only the beginning; there are a lot of things that should be done, but let's just start with these ones. (Italy; B2 VANTAGE; 1993; Italian; Pass)
