# FORM: 'BY ITSELF'

**EGP #914** · **B2** · `egp-914`

## Can-do

Can use the reflexive pronoun 'itself' with 'by' to mean alone or without any help.

## Example

If an animal is kept by itself , with no one to keep it company, it will get lonely and very sad. (First Certificate in English; B2; Danish)
