# FORM/USE: 'THESE ONES', 'THOSE ONES' SUBSTITUTION

**EGP #953** · **B2** · `egp-953`

## Can-do

Can use 'these ones', 'those ones' as a substitute for plural countable nouns that have previously been mentioned.

## Example

This is only the beginning; there are a lot of things that should be done, but let's just start with these ones. (Italy; B2 VANTAGE; 1993; Italian; Pass)
