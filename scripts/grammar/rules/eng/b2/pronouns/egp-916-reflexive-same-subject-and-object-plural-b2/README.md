# FORM: SAME SUBJECT AND OBJECT, PLURAL

**EGP #916** · **B2** · `egp-916`

## Can-do

Can use plural reflexive pronouns to refer to actions where the subject and object of the verb are the same.

## Example

In this way we will be able to enjoy ourselves even if this is not well-paid work. (First Certificate in English; B2; Italian)
