# FORM: PLURAL, AFTER PREPOSITIONS

**EGP #915** · **B2** · `egp-915`

## Can-do

Can use plural reflexive pronouns after prepositions where the object of the preposition is the same as the subject of the verb.

## Example

Doing sports is an excellent way to relax and it can help us to feel good about ourselves. (First Certificate in English; B2; Hungarian)
