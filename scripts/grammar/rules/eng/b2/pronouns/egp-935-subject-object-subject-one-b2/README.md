# FORM: (SUBJECT) 'ONE'

**EGP #935** · **B2** · `egp-935`

## Can-do

Can use 'one' as a generic personal pronoun in the subject position to mean people in general. ► generic pronouns

## Example

If one doesn't live close enough to walk to work, one can choose to get there by bicycle or by car. (First Certificate in English; B2; Swedish)
