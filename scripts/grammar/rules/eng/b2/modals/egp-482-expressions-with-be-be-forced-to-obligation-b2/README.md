# USE: 'BE FORCED TO', OBLIGATION

**EGP #482** · **B2** · `egp-482`

## Can-do

Can use 'be forced to' to talk about an unnamed obligation, where the circumstances are beyond the control of the speaker/writer.

## Example

I don't like to be forced to do something that I don't want to do. (Poland; B2 VANTAGE; 1993; Polish; Pass)
