# USE: 'BE BOUND TO', CERTAINTY

**EGP #478** · **B2** · `egp-478`

## Can-do

Can use 'be' (+ modifier) 'bound to' to talk about something certain or inevitable.

## Example

I assure you that it is bound to be popular with different clients, especially young people and white-collar workers. (China; B2 VANTAGE; 2008; Chinese; Pass)
