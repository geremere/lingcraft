# FORM: WITH ADVERBS

**EGP #541** · **B2** · `egp-541`

## Can-do

Can use 'must' with an increasing range of adverbs (including 'all', 'never', 'strongly', 'first') in the normal mid position after the modal verb. ► adverbs

## Example

To sum up, we must all act immediately because the existence of humanity may be in danger. (Greek, B2 VANTAGE)
