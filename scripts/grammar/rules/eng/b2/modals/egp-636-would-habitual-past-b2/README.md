# USE: HABITUAL PAST

**EGP #636** · **B2** · `egp-636`

## Can-do

Can use 'would' to talk about habitual actions and events in the past.

## Example

[talking about a job that the speaker did last year] In my opinion I worked very hard. I would spend a lot of hours at work. (Chinese, B2 VANTAGE, Pass, 2011)
