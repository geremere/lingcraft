# FORM/USE: 'IT' + LINKING VERB + ADJECTIVES + CLAUSE, HEDGING

**EGP #431** · **B2** · `egp-431`

## Can-do

Can use 'it' + linking verb + adjective + ('that') clause to make an assertion less direct.

## Example

It does not seem possible that we can live without any private life. (Japan; B2 VANTAGE; 2000; Japanese; Pass)
