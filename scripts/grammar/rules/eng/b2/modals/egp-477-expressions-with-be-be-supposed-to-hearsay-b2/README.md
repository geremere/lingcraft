# USE: 'BE SUPPOSED TO', HEARSAY

**EGP #477** · **B2** · `egp-477`

## Can-do

Can use 'be supposed to' to talk about hearsay or supposition.

## Example

That woman is supposed to have killed her husbands (at least two), because she wanted their money. (Spain; B2 VANTAGE; 2000; Spanish - European; Pass)
