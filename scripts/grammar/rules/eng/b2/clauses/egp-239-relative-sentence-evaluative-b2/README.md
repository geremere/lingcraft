# FORM/USE: SENTENCE, EVALUATIVE

**EGP #239** · **B2** · `egp-239`

## Can-do

Can use a relative clause to refer to a whole clause or sentence, often to express an opinion or evaluation or give a reason.

## Example

It is now possible to send a letter and receive an answer within ten minutes, which is a good thing if you want to buy a house, a car etc. (Denmark; B2 VANTAGE; 1999; Danish; Pass)
