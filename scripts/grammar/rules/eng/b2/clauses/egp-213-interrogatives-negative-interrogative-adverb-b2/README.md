# FORM: NEGATIVE INTERROGATIVE + ADVERB

**EGP #213** · **B2** · `egp-213`

## Can-do

Can form negative interrogative clauses with an adverb in mid position, between the subject and the main verb.

## Example

Money - hasn't it always been one of the most important problems for students? (Japan; B2 VANTAGE; 2000; Japanese; Fail)
