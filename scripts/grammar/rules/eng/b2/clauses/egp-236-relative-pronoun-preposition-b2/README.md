# FORM: PRONOUN + PREPOSITION

**EGP #236** · **B2** · `egp-236`

## Can-do

Can use defining relative clauses and non-defining relative clauses ending in a preposition, with 'who/which/that' as the complement of the preposition.

## Example

Thank you very much for having provided us with valuable information about your finance services, which we are greatly interested in. (China; B2 VANTAGE; 2008; Chinese; Pass)
