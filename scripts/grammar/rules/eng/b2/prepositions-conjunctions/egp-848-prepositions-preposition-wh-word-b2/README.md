# FORM/USE: PREPOSITION + 'WH-'WORD

**EGP #848** · **B2** · `egp-848`

## Can-do

Can use preposition + relative pronoun as complement, to avoid preposition stranding, often in formal contexts. ► Clauses: relative

## Example

According to your advertisement in a language magazine, you have a vacancy in which I am very interested. (Switzerland; B2 VANTAGE; 1998; German; Pass)
