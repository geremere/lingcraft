# FORM: DIRECT SPEECH, REPORTING CLAUSE, MID POSITION

**EGP #1153** · **B2** · `egp-1153`

## Can-do

Can report speech and thought directly using the reporting verb in the mid position of the reported clause.

"No problem", I thought, "there is only one person". (Botswana; B2 VANTAGE; 1993; Vietnamese; Pass)
