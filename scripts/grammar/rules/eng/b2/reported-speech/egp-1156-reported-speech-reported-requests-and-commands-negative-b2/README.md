# FORM: REPORTED REQUESTS AND COMMANDS, NEGATIVE

**EGP #1156** · **B2** · `egp-1156`

## Can-do

Can report requests and commands with 'ask' or 'tell' + direct object + 'not' + 'to-'infinitive.

## Example

Meanwhile, she told me not to be scared but the place was very... old. (Brazil; B2 VANTAGE; 1993; Portuguese; Pass)
