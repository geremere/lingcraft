# FORM/USE: 'NEVER', INVERTED FRONT POSITION, FOCUS

**EGP #1193** · **B2** · `egp-1193`

## Can-do

Can use 'never' in front position followed by an inverted subject (most commonly 'I') + main verb, to give focus.

## Example

Never have I seen such a realistic and impressive film before. (Argentina; B2 VANTAGE; 2008; Spanish - Latin American; Pass)
