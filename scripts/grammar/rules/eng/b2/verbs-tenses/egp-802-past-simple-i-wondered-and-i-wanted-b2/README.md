# USE: POLITENESS: 'I WONDERED' AND 'I WANTED'

**EGP #802** · **B2** · `egp-802`

## Can-do

Can use the past simple with 'I wondered' and 'I wanted' as politeness structures, when making polite requests and thanking.

## Example

So, I wondered if you could introduce me to somebody who knows how to use a camera, so that I will be able to record my trip for you. (B2, Greek)
