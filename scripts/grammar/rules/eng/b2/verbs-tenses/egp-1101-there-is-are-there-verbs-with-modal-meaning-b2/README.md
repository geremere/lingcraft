# FORM: 'THERE' + VERBS WITH MODAL MEANING

**EGP #1101** · **B2** · `egp-1101`

## Can-do

Can use 'there' with other verbs with modal meaning + 'be' + complement.

## Example

I figured out that there had to be matches somewhere; Bob, who owned the cabin, had told me that it was well equipped. (Sweden; B2 VANTAGE; 1993; Swedish; Pass)
