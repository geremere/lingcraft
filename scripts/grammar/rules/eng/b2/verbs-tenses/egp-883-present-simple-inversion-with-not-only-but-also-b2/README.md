# FORM: INVERSION WITH 'NOT ONLY ? BUT ALSO'

**EGP #883** · **B2** · `egp-883`

## Can-do

Can use the inverted form of the past simple with auxiliary 'do', in the phrase 'not only ? but also'.

## Example

Not only do they save you filing time, but also they save office space. (First Certificate in English, B2, Chinese)
