# FORM/USE: WITH 'STILL'

**EGP #832** · **B2** · `egp-832`

## Can-do

Can use the negative form of the present perfect simple with 'still' to emphasise that something that was expected to happen continues not to happen.  ► adverbs

## Example

I still haven't read the role but when I read it, I was very excited and I accepted Mr Brown's offer. (Greece; B2 VANTAGE; 2002; Greek; Pass)
