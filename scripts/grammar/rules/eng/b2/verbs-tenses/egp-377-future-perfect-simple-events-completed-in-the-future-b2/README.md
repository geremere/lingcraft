# USE: EVENTS COMPLETED IN THE FUTURE

**EGP #377** · **B2** · `egp-377`

## Can-do

Can use the future perfect simple with 'will' to talk about something which is expected to be completed (or not completed) by a certain point in the future.

## Example

There is no problem if you want to leave at 4.30 pm as the match will have finished by that time. (Greece; B2 VANTAGE; 2008; Greek; Pass)
