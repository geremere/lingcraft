# FORM: 'TO'-INFINITIVE OR '-ING' FORM, MEANING

**EGP #1091** · **B2** · `egp-1091`

## Can-do

Can follow some verbs with a 'to'-infinitive or an '-ing' form, with a change in meaning.

## Example

He said if you need to change the time, remember to contact him to make a new appointment. (Malaysia; B2 VANTAGE; 1999; Chinese; Pass)
