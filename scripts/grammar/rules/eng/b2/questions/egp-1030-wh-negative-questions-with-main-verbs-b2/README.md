# FORM: NEGATIVE QUESTIONS WITH MAIN VERBS

**EGP #1030** · **B2** · `egp-1030`

## Can-do

Can use 'wh-'words + the negative form of auxiliary 'do' + subject + main verb to form 'wh-'questions.

## Example

You still have this agonising headache. Why don't you go to your doctor? (Polish, B2 VANTAGE)
