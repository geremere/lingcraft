# FORM/USE: 'THE MORE … THE MORE …'

**EGP #297** · **B2** · `egp-297`

## Can-do

Can use the in comparative phrases 'more', 'less', 'worse', 'better … the more', 'less', 'worse …' to talk about one thing that is affected by another. ► comparative clauses

## Example

[talking about how watching TV is bad for you] I mean that you can watch one or two hours a day but the more you watch, the worse you become. (Greece; B2 VANTAGE; 1993; Greek; Pass)
